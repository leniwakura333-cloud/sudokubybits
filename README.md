# sudokubybits

🚀 How to Run the App

Option 1: Run on CodePen
  1.   Open https://codepen.io/pen/
  2.   Create a new Pen.
  3.   Copy the:
		- HTML code into the HTML panel
		- CSS code into the CSS panel
		- JavaScript code into the JS panel
  4. Hit Run or refresh the preview, the Sudoku app should appear.

Option 2: Run on JSFiddle
  1.   Go to https://jsfiddle.net/
  2.   Paste
		- HTML code into the HTML panel
		- CSS code into the CSS panel
		- JavaScript code into the JS panel
  3. Click Run. The Sudoku app will load in the preview area.

Option 3: Run Locally on Your Computer 
  1.   Place your files in a folder. 
		- index.html
		- style.css
		- script.js
  2. Make sure your index.html contains the links:
     <link rel="stylesheet" href="style.css">
	 <script src="script.js" defer></script>

Option 4: Run on Replit
  1. Go to https://replit.com/
  2. Create a new HTML/CSS/JS project.
  3. Replace the default files with the index.html, style.css, and script.js.
  4. Click Run.
